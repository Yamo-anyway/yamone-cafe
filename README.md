# Yamone Cafe

개인용 안드로이드 카페 브라우저 및 독립 백그라운드 새로고침 앱입니다.

- 앱 내 WebView에서 네이버에 직접 로그인합니다.
- 사용자가 읽는 브라우저와 별도 WebView로 지정한 카페 주소를 새로 불러옵니다.
- 기본 31분 00초~35분 00초 범위에서 매회 정수 초 단위로 간격을 선택합니다.
- 브라우저 열람과 수동 새로고침은 자동 일정에 영향을 주지 않습니다.
- 사용자 시작/일시정지/재개/중지, 실행 알림과 기록을 제공합니다.

소스 초기 구성 중입니다. 실제 기기에서 로그인 및 화면 꺼짐 상태의 동작을 확인해야 합니다.
로그인 정보, 쿠키, 개인 APK 서명키는 저장소에 올리지 않습니다.
Google Play 배포 및 공개 Release 자동 배포는 사용하지 않습니다.

저장소의 실제 이름은 `yamne-cafe`, 앱의 표기 이름은 **Yamone Cafe**입니다.
