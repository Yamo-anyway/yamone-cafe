# 실기기 확인표

APK 빌드 성공과 실제 기기 동작 성공은 다릅니다. 아래 항목은 사용자 기기에서 확인해야 합니다.

| 시험 | 확인 내용 |
|---|---|
| 최초 설치 | 실행 시 브라우저 표시, 입력/버튼 잘림 없음, 다크 모드 가독성 |
| 로그인 | 앱 안에서 네이버 로그인, 로그인 성공 뒤 카페 표시, 다른 앱의 쿠키를 가져오지 않음 |
| 최초 자동 로딩 | 카페 주소 저장 후 시작 → 즉시 시도 및 결과 기록, 다음 시각 표시 |
| 화면 분리 | 게시글 중간 스크롤 → 자동 실행 발생 → 화면/스크롤 그대로 |
| 일정 독립 | 자동 실행 도중 글 읽기, 직접 새로고침, 탭 전환, 앱 다시 열기 → 예정 시각 불변 |
| 홈 화면/다른 앱 | 해당 시각 자동 로딩 기록, 화면을 갑자기 앞으로 띄우지 않음 |
| 화면 꺼짐 | 충전/비충전 각각 최소 2주기, 예정 시각 대비 실제 기록 비교 |
| 일시정지 | 남은 시간 정지 및 알람 취소, 재개하면 남은 시간 유지 |
| 중지 | 진행 중 로딩/예약 취소, 지속 알림 사라짐, 후속 시도 없음 |
| 네트워크 없음 | 실패 기록 후 다음 주기 예약, 폭주 재시도 없음 |
| 로그인 만료 | 로그인이 필요한 화면으로 이동 시 일시정지, 재로그인 후 재개 |
| 강제 종료 | 설정의 강제 중지 뒤 자의적인 복구 없음 |
| 재부팅 | 자동 재개 꺼짐이면 중지, 켜짐이면 OS 허용 범위에서 복구 |
| 프로세스 회수 | URL/히스토리/스크롤 가능한 범위 복원, 동적 작성 내용 보존은 보장하지 않음 |

## 참고

- 간격 최소값은 31분입니다. 주기를 짧게 줄여 서버를 반복 요청하는 테스트 모드는 넣지 않았습니다.
- 로그의 `로드`는 페이지 완료 이벤트일 뿐 실제 방문 집계·계정 인증 성공을 뜻하지 않습니다.
- 기록에는 네이버 계정 정보나 쿠키를 넣지 않습니다. 기록 공유 전 직접 확인하세요.
